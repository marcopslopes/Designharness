# Impeccable marketing site — vision, IA, and reusable strategy

**Captured:** 2026-08-07  
**Source:** [impeccable.style](https://impeccable.style/) + docs IA ([docs](https://impeccable.style/docs/), [context](https://impeccable.style/docs/context/))  
**Purpose:** Personal notes for exposing *our* design harness as a designer workflow / agent product — reuse their web strategy, not their brand or claims that don't fit how product designers work.

---

## Positioning (the vision, one sentence)

**“The missing design vocabulary for agents.”**

Not: a list of AI features.  
Not: “automate all design.”  
Yes: *agents already write UI — this is the language + guardrails so they stop shipping slop and start working like a design workflow.*

**Reusable frame for our harness:** designer workflow as a **shared vocabulary the agent already knows**, not “another chatbot that designs.”

---

## Site IA (scroll story)

| Block | Job | Reuse for our product |
|-------|-----|------------------------|
| **Hero** | Problem + promise in one line (slop → steer → live → dice) | One promise: e.g. “A design workflow for agents that knows your product” / “Design harness that stays on DS” |
| **Proof carousel** | Social proof before features | Quotes from designers who shipped with it |
| **Anti-demo** | Before = AI slop SaaS; After = real craft | Show “generic AI UI” vs “our harness / your design system” |
| **The Language** | Commands as *vocabulary*, shown as a real chat + browser | Interactive: “say X → agent does Y” (skills as verbs) |
| **Signature magic** | Worlds/dice (their unique wedge) | Our wedge: routing + DS gate + review board + detector — pick *one* hero mechanism |
| **Ready to drop in** | 5 trust pillars, not a feature dump | Same shape: context · system · modes · quality gate · install |
| **Get started** | One install command + first run | `npx … install` → `/init` equivalent |
| **Edges** | Extension, CI detect, newsletter | Optional: CI detector, how-to, changelog |

**Docs IA** (separate from marketing): Install → Context (PRODUCT/DESIGN) → Commands grouped by job (Start / Plan / Review / Refine / Iterate) — not alphabetical skill spam.

## Content strategy worth copying (mechanisms, not words)

1. **Name the enemy** — “AI slop / model defaults.” Our parallel: “freestyle agent UI that bypasses your design system's tokens & patterns.”
2. **Sell a language, not a tool list** — `/polish`, `/audit`, `/typeset` as verbs. Our parallel: route-able asks (“audit this”, “variation mockups”, “build this screen”).
3. **Show the loop, don’t list skills** — agent thread + in-app browser + command picker. Our parallel: Cursor chat + Design Harness + skill routing.
4. **Context files as the product** — `PRODUCT.md` / `DESIGN.md` once, every command reads them. Our parallel: designer profile + `COMPANY-*` + `tokens.css` + task `brief.md` — “plug in once, every agent inherits.”
5. **Modes by surface job** — Persuade / Operate / Read / Experience. Our parallel: product vs marketing vs docs (product work leans Operate).
6. **Quality as a ship gate** — hooks + detector + “PR ready.” Our parallel: `design-detector` + `audit` PASS before share/publish.
7. **One command, many harnesses** — same skill, recompiled for Cursor/Claude/Gemini. Maps to “any company plug-in” vision.
8. **Trust pillars, not capability soup** — five numbered “Ready to drop in” cards beat a 23-row table on the homepage.

---

## What *not* to reuse blindly

- **“Never touch Figma”** — wrong for product teams (designers live in Figma; our story is *with* Figma + Design Harness, not instead).
- **Worlds/dice as the hero** — their wedge for marketing sites; ours is DS fidelity + squad workflow.
- **“Fully automated agents” as the headline** — their site sells **steerable** automation (you pick command / element / world). Full autopilot isn’t the pitch; **vocabulary + guardrails + one install** is.

---

## Reusable homepage outline for *our* harness

1. **Hero:** “Design workflow for agents that already know your product.”
2. **Enemy:** Freestyle AI UI that invents tokens / breaks patterns.
3. **Loop demo:** Ask → routed skill → Design Harness / Figma / detector.
4. **Vocabulary:** 6–8 verbs (kickoff, build, critique, audit, review board, workload…) — not all 20+.
5. **Wedge:** e.g. “Tokens + patterns as hard gates” or “Review board before build.”
6. **Trust:** Respects DS · Product context · Artifact types · Ship gate · Works in Cursor.
7. **Start:** Install / open lab / run onboarding.
8. **Docs:** Getting started · Context · Skills by job · Detector.

---

## Bottom line

Their web strategy is **language + context + demo of the agent loop + trust that it respects your system**. That’s the reusable playbook for exposing our harness as a designer workflow — not cloning their “anti-slop marketing site” brand, and not promising full autopilot.
