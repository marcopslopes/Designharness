# ia-methods

Information architecture research - card sorting, tree testing, navigation analysis.

## What It Does

**IA research methods** including:
- Card sorting (open/closed)
- Tree testing
- Navigation analysis
- Taxonomy development
- Findability studies

**Structure your information** - where things belong.

---

## Methods

### Card Sorting
Users group and label content - reveals mental models.

### Tree Testing
Users find content in proposed structure - validates IA.

### Navigation Analysis
Review existing structure - identify issues.

---

## Example

```
You: "Run card sort for provider settings"

Output:
- Online card sort setup (OptimalSort)
- 30 cards (all settings options)
- Open sort (participants create groups)
- n=20 target
- Analysis: Cluster dendogram
- Recommendation: 5 top-level categories
```
