# inspiration-scouting

Discovers design inspiration - patterns, trends, best-in-class examples.

## What It Does

**Scouts inspiration** by:
- Finding relevant examples
- Analyzing what works
- Extracting principles
- Creating mood boards

**Curated inspiration** - not aimless browsing.

---

## When to Use

Use when you need:
- Visual direction
- Pattern examples
- Trend research
- Style exploration

### Trigger Phrases
```
"Find inspiration for [style]"
"Examples of [pattern]"
"Best-in-class [feature]"
"Create mood board"
```

---

## Example

```
You: "Find inspiration for celebration animations"

Output:
- Duolingo streak celebration (confetti + sound)
- Strava achievement unlock (badge reveal)
- Calm milestone (serene animation)
- Apple Watch rings (satisfying close)

Principles:
- Immediate feedback
- Appropriate emotion (match context)
- Respectful of user attention
```
