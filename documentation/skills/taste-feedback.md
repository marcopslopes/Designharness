# taste-feedback

Subjective design review - polish, craft, aesthetic quality.

## What It Does

**Craft review** focusing on:
- Visual hierarchy
- Typography quality
- Spacing rhythm
- Color harmony
- Overall polish

**The eye test** - does it feel right?

---

## When to Use

Use after technical compliance:
```
audit (passes) →
accessibility (passes) →
taste-feedback (polish layer)
```

---

## Example

```
Taste Feedback: City Leaderboard

✅ Strong visual hierarchy (badge → city → bookings)
⚠️ Spacing feels tight around rank badges (add 2px)
❌ Typography: Rank numbers too light (increase weight)
✅ Color usage restrained and purposeful
⚠️ Card shadows could be softer (reduce opacity 10%)

Overall: 8/10 craft quality
Main issue: Typography weight on badges
```
