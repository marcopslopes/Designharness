# cognitive-accessibility

Cognitive load review - clear language, simple flows, reduced complexity.

## What It Does

**Reviews cognitive load** by checking:
- Language clarity
- Task complexity
- Information hierarchy
- Memory requirements
- Decision fatigue

**Beyond WCAG** - designing for everyone's brain.

---

## When to Use

Use `cognitive-accessibility` when you want to:
- Simplify complex flows
- Improve clarity
- Reduce cognitive load
- Make onboarding easier

### Trigger Phrases
```
"Check cognitive accessibility"
"Is this too complex?"
"Simplify this flow"
"Reduce cognitive load"
```

---

## What It Checks

### 1. Language
- Plain language (8th grade reading level)
- Short sentences
- Active voice
- Familiar words

### 2. Chunking
- 5-7 items max per group
- Clear sections
- Progressive disclosure

### 3. Memory Load
- Don't require remembering across screens
- Persistent context
- Clear breadcrumbs

### 4. Task Complexity
- Single task per screen
- Clear next steps
- Undo/back options

---

## Example Review

```
Cognitive Accessibility Review: Onboarding Flow

❌ Step 1: Too many fields (12 fields on one screen)
Fix: Split into 3 screens (4 fields each)

❌ Step 2: Jargon ("Configure your preferences")
Fix: "Set up your account"

✅ Step 3: Clear progress (2 of 3)

❌ Step 4: Requires remembering info from Step 1
Fix: Show summary card with Step 1 info

✅ Step 5: Single clear CTA
```
