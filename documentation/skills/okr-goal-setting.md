# okr-goal-setting

Drafts OKRs for design work - objectives, key results, measurable goals.

## What It Does

**Creates OKRs** that:
- Define objectives (qualitative)
- Set key results (quantitative)
- Align with company goals
- Track progress

**Measurable design goals** - know what success looks like.

---

## OKR Structure

```
Objective: Ambitious, qualitative goal
Key Result 1: Measurable outcome
Key Result 2: Measurable outcome
Key Result 3: Measurable outcome
```

---

## Example

```
You: "Create OKRs for provider engagement"

Output:
Objective: Dramatically improve provider engagement and retention

Key Results:
1. Increase DAU from 42% to 55%
2. Reduce churn from 12% to 8%
3. Improve NPS from 45 to 60

Initiatives (how):
- Ship city leaderboard (competitive motivation)
- Redesign home tab (clear value prop)
- Improve onboarding (reduce drop-off)
```
