# Sources — everyday-banking-dashboard

Project-scoped **link catalog** for this task only. Same idea as
`COMPANY-SOURCES.md` (org-pack), narrower scope.

**Links are canonical** — do not paste full article/Doc bodies here.
Synthesis and skill output still go in `findings.md`; this file is the
scannable URL table agents reopen on resume.

**Append rows, never delete prior ones** (strike or note “retired” in
Notes if a link goes bad).

## When to add a row

- Designer pastes an article, Doc, deck, competitor page, FigJam, etc.
  **for this project**
- A skill run cites a durable external URL worth finding again
- Not global/team-wide → those go in `COMPANY-SOURCES.md` (org-pack)
- Not personal-only → those go in `designer-context.local/`
